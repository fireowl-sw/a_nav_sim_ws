# Git 分支创建与切换指南

## 一、创建分支

### 一步完成创建并切换

```bash
git checkout -b learn
```

这条命令会**同时完成两件事**：

1. 创建 `learn` 分支
2. 自动切换到该分支

> 💡 **提示**：无需单独执行创建命令，`-b` 参数一步到位。

---

## 二、切换分支

### 切换到已存在的分支

```bash
git checkout learn          # 切换到 learn 分支
git checkout main          # 切换到 main 分支
```

### 从远程拉取并创建本地分支

```bash
git checkout -b learn origin/learn
```

---

## 三、查看分支


| 命令             | 说明                   |
| ---------------- | ---------------------- |
| `git branch`     | 查看本地所有分支       |
| `git branch -a`  | 查看本地和远程所有分支 |
| `git branch -vv` | 查看分支关联的远程分支 |

---

## 四、获取分支历史版本

### 1. 查看提交历史

```bash
git log --oneline              # 简洁查看当前分支历史
git log --all --oneline --graph # 查看所有分支的图形化历史
```

### 2. 切换到历史版本

```bash
git checkout <commit-hash>
# 示例
git checkout a1b2c3d
```

切换后项目会变成该历史版本的状态。

> ⚠️ **注意**：切换到历史版本后处于「分离头指针」状态，如需保存修改，请创建新分支。

### 3. 基于历史版本创建新分支

```bash
git checkout a1b2c3d           # 先切换到历史版本
git checkout -b new-branch     # 基于该版本创建新分支
```

---

## 五、文件修改历史

```bash
# 查看某文件的修改历史
git log --all --oneline -- <文件路径>

# 对比两个历史版本的差异
git diff <commit-hash-1> <commit-hash-2>
```

---

## 六、完整操作流程示例

```bash
# 1. 创建并切换到新分支
git checkout -b learn

# 2. 创建文档目录
mkdir -p learn

# 3. 提交更改
git add .
git commit -m "docs: 添加学习记录目录"

# 4. 后续在该分支上记录内容即可
```

---

## 七、常见问题


| 问题                 | 解决方案                                     |
| -------------------- | -------------------------------------------- |
| 忘记当前在哪个分支   | `git branch` 查看，带 `*` 标记的是当前分支   |
| 切换后想回到最新版本 | `git checkout <分支名>` 切换回目标分支       |
| 历史版本修改后丢失   | 创建新分支保存：`git checkout -b new-branch` |
